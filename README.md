# ⚡ CYBER AI PORTAL ⚡

مرحباً بكم في **المركز السيبراني الشامل**، وهي بوابة مصممة بأسلوب "الهكر" (Hacker Aesthetic) تهدف إلى تجميع أهم الموارد للأمن السيبراني، الذكاء الاصطناعي، والبرمجة في مكان واحد.

## 🚀 المميزات
- **شاشة دخول آمنة:** نظام حماية بسيط يتطلب كلمة مرور للدخول إلى المحتوى.
- **تصميم عصري:** واجهة مستخدم تعتمد على ألوان النيون (Neon Green) والوضع الليلي العميق.
- **أدوات مدمجة:** أداة لتوليد كلمات مرور قوية ومشفرة برمجياً داخل الموقع.
- **روابط سريعة:** وصول مباشر إلى أهم المنصات مثل ChatGPT، Kali Linux Tools، و W3Schools.

## 🛠️ التقنيات المستخدمة
- **HTML5**: لبناء هيكل الموقع.
- **CSS3**: للتصميم والتحريك (Animations) وتنسيق الألوان.
- **JavaScript**: لإدارة منطق كلمة المرور وأداة توليد كلمات السر.

## 🔑 كيفية التشغيل
1. قم بتحميل الملف `index.html`.
2. افتح الملف باستخدام أي متصفح ويب.
3. استخدم كلمة المرور الافتراضية للدخول: `12`.
